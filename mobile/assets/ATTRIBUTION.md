# Preview assets

Editorial cover photographs are fetched from Unsplash image URLs listed in `src/data/demo/seed.ts`.
They are sample artwork, not channel-owned content. Replace with owned/licensed catalogue artwork before release.

The bundled `video/flower.webm` comes from MDN's `cc0-videos` examples:
https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.webm
It is used only as clearly labelled sample playback footage; editorial titles/durations are illustrative.
The matching `public/preview.webm` copy serves the browser preview without a video CDN.

The CloudLynk preview icon is an original vector in `icon.svg`, with a PNG export for Android packaging.

UI icons come from the installed `lucide-react-native` package and its license.
